# Greenfield Course Registration System

This project is a web-based course registration system developed using HTML, CSS, JavaScript, PHP, MySQL, and XML.

## Features
- Student registration and login
- Course browsing and registration
- Admin dashboard
- Course management
- Authentication and session handling

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XML
- XAMPP
